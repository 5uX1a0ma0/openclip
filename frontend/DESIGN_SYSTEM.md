# 前端样式约定

本应用沿用 SolidJS、原生 CSS 和 Lucide 图标。整体是密集的剪贴板工具界面，保留既有青绿强调色、Inter 系统字体栈、明暗主题和 720px 响应式断点。

## 保留式审查

原有流程依次为密钥管理、文本编辑和内容列表，三种弹窗分别显示密钥二维码、摄像头扫描和图片预览。保留页面标题、导航文案、桌面三列主操作和手机单列排列。设计变化 / 动效 / 密度按 2 / 1 / 7 控制：只增加明确要求的链接工具及必要可访问性修复。

原有问题包括编辑区无可见焦点、输入控件缺少名称、弹窗无法用 Escape 关闭或约束焦点、提示不播报、加载旋转未适配减少动态效果。深色主按钮原有文字对比度约 3.95:1，将背景从 `#2a8a81` 调整为 `#22746d` 后约为 5.27:1；深色占位符略微提亮。其余布局与计算值优先保留。

## 变量

`src/styles.css` 的 `:root` 定义页面、表面、正文、次级文字、边框、控件和强调色；深色主题在 `prefers-color-scheme: dark` 中覆盖相同变量。控件圆角为 `--radius-control`（8px），工具栏为 `--radius-toolbar`（10px）；控件高度为 `--height-control`（40px）。常用控件和区块间距分别为 `--space-control`（8px）和 `--space-section`（18px）。弹窗与提示层级为 `--layer-modal` 和 `--layer-toast`。

| 变量 | 值和用途 |
| --- | --- |
| `--font-size-caption/body/preview/title/panel` | 13 / 14 / 15 / 16 / 17px，依次用于辅助文字、正文、预览、表单标题、区块标题 |
| `--space-1` 至 `--space-9` | 4 / 6 / 7 / 8 / 10 / 12 / 14 / 18 / 24px，提取自现有间距 |
| `--color-focus` / `--color-focus-soft` | 实色键盘轮廓与输入框柔和外圈，两种主题分别定义 |
| `--layer-modal/image-modal/toast/skip-link` | 20 / 24 / 30 / 31，弹窗、大图、提示、跳转链接 |

新增颜色、间距或尺寸应先复用这些变量，并检查两种主题的对比度。保留现有语义色：发送为绿色，危险操作为红色，提示为蓝色。浏览器 `theme-color` 与页面背景保持一致。

## 组件与状态

- 按钮和文件上传入口的最小高度为 40px，编辑区轻量工具为 32px。主按钮、次按钮、危险按钮、图标按钮沿用现有外观；悬停加深底色，禁用降低透明度，键盘焦点显示轮廓。
- 输入框、选择器、编辑区使用相同边框、圆角和焦点色。编辑区位于卡片内时以内部轮廓标出键盘焦点。所有输入控件必须有可访问名称。
- `icon-toggle` 和编辑区清理开关使用 `role="switch"` 与 `aria-checked`。编辑区工具行独立于原有三列操作行。
- 卡片、提示、状态栏和弹窗保持原有间距与颜色。动态提示通过 `aria-live="polite"` 播报。
- 三类弹窗使用 `role="dialog"`、`aria-modal`、Escape 关闭、Tab 焦点约束及关闭后焦点恢复。扫码弹窗关闭时继续释放摄像头资源。

## 响应式和维护

桌面内容最大宽度为 1040px。宽度不超过 720px 时，密钥区、编辑区三个主操作和内容卡片改为单列；新增工具行可换行。用户文本及长链接须允许换行，弹窗高度受视口限制并可滚动。200% 缩放时不应产生横向溢出。

保留现有动效用途，只为加载状态旋转；`prefers-reduced-motion: reduce` 关闭该动画。新交互必须提供键盘操作、可见焦点和可访问名称。调整 CSS 后同时检查桌面与手机宽度下的明暗主题。

CSS 依次组织为变量、基础与控件状态、组件、响应式、深色主题和减少动态效果。应通过变量覆盖主题颜色，避免新增同值重复规则或仅靠隐藏横向溢出掩盖尺寸问题。
